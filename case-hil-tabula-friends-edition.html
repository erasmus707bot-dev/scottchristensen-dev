HIL + Tabula Friends Edition

Two small offline desktop apps I package for friends on Windows and Linux.

Built with Claude under my direction · Python, Windows installer, Debian packaging, ffmpeg

← All projects

What it does

  • HIL — a toolbar for screenshots and screen recordings.
  • Tabula — a notepad with a tab per project, to-dos and pictures.
  • Everything stays on the user's computer — no internet needed.

A real problem it solved

Version 1.0.0 installed on Windows and showed nothing — no window, no error. I made it a standing rule: every Windows build is tested in a Windows virtual machine before it reaches a real PC. Version 1.0.1 passed the VM test, with both apps launching, and shipped.

For non-technical users

A plain-English install guide: what the Windows “protected your PC” warning means, where screenshots and videos are saved, and how to send a picture into a note. The Windows installer needs no admin password, and ffmpeg is included so recording works out of the box.
