The tests passed. The button didn't.

Why I click through every change by hand after the automated tests go green.

Project: ProReady (formerly SonoVault) · built with Claude under my direction

← All projects

The problem

Every automated test was green. But when I clicked Add image in a live walk-through, nothing happened — no error, no image, no message.

What I found

The button sat inside a form that was nested inside another form. Browsers don't allow that, so the click went nowhere. The automated tests never clicked through the page the way a person does.

The fix

  • Fixed the page structure so the button submits the right form.
  • Added a guard test so the same mistake fails the build next time.

Takeaway

Automated tests prove the code does what it was told. A real click-through proves it does what people need. I do both before I call something done.
