Epochron

A standalone Android calendar built for privacy and careful releases.

Built with Claude under my direction · Kotlin, Jetpack Compose, NWS and NOAA data

← All projects

What it does

Your events with labels, sky events (moon phases, seasons, clock changes, meteor showers), weather and tides on each day, a trip card, and tasks as calendar entries with a done tick. Works with an existing Google calendar.

Privacy by design

  • The app has one network door, and it stays closed until you turn weather on.
  • Location is city-level only.
  • A build check strips any reference to my own server from the version friends get.

Release discipline

  • Release candidate first: test in an Android emulator, then on my real phone, against a written 13-point checklist.
  • 1.0 only after the checklist passes — so friends never get an untested build.
  • Each release ships with a checksum file, release notes and a short friend guide.
  • Last full test run: 54 of 54 passing (version 0.6.0).

Status

The 1.0 release candidate is prepared and heading into checklist testing.
